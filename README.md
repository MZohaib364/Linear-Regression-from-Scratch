# Linear Regression from Scratch: Predicting Real Estate Prices

This project demonstrates the implementation of Linear Regression from scratch using numpy and pandas. The dataset used is real_estate, focusing on predicting real estate prices based on various property-related features. This implementation covers core aspects of machine learning, such as data preprocessing, model training, testing, and evaluation.

## Features:
- Implemented from scratch without external libraries like scikit-learn.
- Handles both numerical and categorical features effectively.
- Includes core machine learning functionalities:
- Data preprocessing (scaling, handling missing values).
- Training and testing split.
- Gradient descent optimization for linear regression.
- Evaluation metrics including Mean Squared Error (MSE)

## Learning Outcomes:
This project highlights:
- The mathematical concepts underlying linear regression.
- The use of gradient descent for parameter optimization.
- Building regression models without the use of high-level machine learning libraries.
